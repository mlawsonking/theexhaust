# The Exhaust

*An observatory for shadow statistics.* Live, unofficial, receipts-attached versions of the numbers society currently waits for — computed from public exhaust data, validated by running history backwards, and graded in public.

**Start here:** [OBSERVATORY.md](OBSERVATORY.md) — the constitution: thesis, phases, covenants, current status. *(The constitution file keeps its name; the public brand is The Exhaust, chosen in Phase 2.)*

**The documents:** [docs/01-VISION.md](docs/01-VISION.md) (ideation) · [docs/02-RESEARCH.md](docs/02-RESEARCH.md) (validation) · [docs/03-GAMEPLAN.md](docs/03-GAMEPLAN.md) (architecture) · [docs/04-BUILDLOG.md](docs/04-BUILDLOG.md) (the build). The autonomy contracts live in [ops/](ops/).
