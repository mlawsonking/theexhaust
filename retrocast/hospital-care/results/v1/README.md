# Hospital/Care Distress v1 — results bundle

Everything a critic needs to rerun or contradict the [report](../../REPORT.md). Generated by
`python -m retrocast.hospital_care.run_v1` at code commit `66d1815` on a clean tree, against
registration commit `d6b78c3` (asserted by the run to be an ancestor of both `HEAD` and
`origin/main`; the run aborts otherwise).

| file | what it holds |
|---|---|
| `scorecard.json` | the machine-readable record the Track Record page renders from: bars, metrics, pass/fail, provenance, every archived object key + sha256, the scored universe and its exclusions, both dumb baselines, the three reported-not-graded variants, and the diagnostics |
| `metrics.json` | headline metrics for the signature, both baselines, the three variants, and the lead-time distribution |
| `pr_curve.csv` | the held-out precision/recall curve. The full curve has one point per distinct score; this is thinned to ≤2,000 evenly spaced points, and the thinning is disclosed rather than silent |
| `calibration.csv` | predicted vs observed by score decile (n = 36,975 per bin) |
| `lead_times.csv` | every true-positive lead time in days (n = 2,138) |
| `cases.csv` | **the receipts** — one row per held-out harm-citation event (4,643): whether the signature flagged it, the crossing week, the lead, the score and all nine feature values at the crossing, plus matched-control counts |

## Reading `cases.csv`

One row per distinct `(facility, week)` harm event in the held-out window. `flagged` is 1 if the
score crossed the train-chosen operating threshold (0.168568) at any point in the 26 weeks before
the event. Matched controls are facilities in the same state and the same 25-bed census band,
observed in the same pre-window.

**This file names facilities by CCN, state and county.** That is deliberate and is not a published
claim: a scorecard whose evidence a critic cannot check is not evidence. The naming gate (covenant
2) governs what may be *published as a claim about a named entity*, and nothing in this index is —
no site page renders a facility, and a failed retrocast opens no named tier.
