# site/

The public static site: home, the **Track Record** scoreboard, retrocasts (pre-registrations), methodology, transparency log; per-index and per-place pages as indexes launch.

Generated by [`sitegen/`](../sitegen/) (Python, stdlib-only, no Node — proven OnScript pattern; theme-aware, self-contained). Build: `python -m sitegen.build` → `site/dist/` (git-ignored, regenerated). **Host: Cloudflare Pages** (the covenant host — GitHub Pages and Vercel Hobby bar commercial use). `dist/` is produced by the Pages build command or a deploy Action.
